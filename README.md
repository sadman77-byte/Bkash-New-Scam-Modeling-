## 📌 Incident Analysis

The video shows that right after money arrives in a victim's bKash account, a fake system update (`Installing system update...`) pops up on their phone screen[cite: 1].
- **Type:** Remote Access Trojan (RAT) / Screen Overlay Attack[cite: 1].
- **Incident:** Complete control of the phone goes into the hands of hackers, and the victim cannot press anything[cite: 1].
- **Result:** Even though the phone returns to normal after a set time, hackers loot all the funds from the account[cite: 1].

## 🔐 Cyber Security Technical Terms

1. **Remote Access Trojan (RAT):** Malicious software used to remotely gain full access to a phone or device[cite: 1].
2. **Overlay Attack:** Placing a fake system update or dialog box over the main app or screen to confuse the user and keep the screen locked[cite: 1].
3. **Smishing / Social Engineering:** Tricking users into installing malicious apps on their devices by sending fraudulent SMS, links, or APK files[cite: 1].
4. **OTP & Screen Hijacking:** Secretly reading device SMS, OTPs, and notifications to empty bKash/bank accounts[cite: 1].

## 🛡️ Prevention & Safety Tips

- 🚫 **Do Not Install Unknown APKs:** Do not install apps from unknown links or third-party sources outside the Google Play Store[cite: 1].
- ⚠️ **Check Accessibility Permissions:** Do not grant unnecessary permissions (such as Accessibility Service, Notification Access) after installing an app[cite: 1].
- 📱 **If Unexpected Updates Appear:** If an abnormal system update or black screen pops up on the screen, immediately:
  1. Turn off mobile data/Wi-Fi[cite: 1].
  2. Completely switch off/restart the phone[cite: 1].
  3. If possible, immediately remove the SIM card to disconnect network access[cite: 1].
- 🔐 **Two-Factor Security:** Never share your bKash secret PIN or OTP with anyone[cite: 1].
